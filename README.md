# TB-RR · Benchmark peruano de predicción genómica de resistencia a tuberculosis

> Hackathon FACI 2026 · UPCH · Reto 1. En construcción: ver estado abajo.

**No es un predictor nuevo.** Es la primera evaluación del desempeño de las herramientas
genómicas existentes (TB-Profiler, catálogo de mutaciones OMS 2.ª ed., y un modelo propio
como cuarto competidor) sobre aislados peruanos, fármaco por fármaco.
